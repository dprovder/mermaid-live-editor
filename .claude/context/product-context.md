# Product Context

## Product Definition

**Mermaid Live Editor** is a web-based application that provides real-time editing, preview, and sharing capabilities for Mermaid diagrams. It serves as the official online playground and editor for the Mermaid diagramming language.

## Target Users & Use Cases

### Primary User Personas

**1. Software Developers & Engineers**

- **Needs:** Quick diagram creation for documentation, design discussions, code reviews
- **Use Cases:** Architecture diagrams, flowcharts, sequence diagrams for technical specs
- **Pain Points:** Need fast, shareable diagrams without complex tooling setup
- **Success Metrics:** Time from idea to shared diagram < 2 minutes

**2. Technical Writers & Documentation Teams**

- **Needs:** Consistent, maintainable diagrams for documentation
- **Use Cases:** User guides, API documentation, process flows
- **Pain Points:** Version control of diagrams, consistent styling across docs
- **Success Metrics:** Diagram integration with markdown/documentation systems

**3. Project Managers & Business Analysts**

- **Needs:** Visual process mapping, workflow documentation
- **Use Cases:** Process diagrams, Gantt charts, organizational charts
- **Pain Points:** Need simple syntax that non-technical users can learn
- **Success Metrics:** Adoption by non-technical team members

**4. Educators & Students**

- **Needs:** Teaching tool for computer science, systems thinking
- **Use Cases:** Algorithm visualization, system design education
- **Pain Points:** Need free, accessible tool with no installation
- **Success Metrics:** Classroom adoption, tutorial completion rates

### Secondary Audiences

**Open Source Contributors**

- Contributing to Mermaid ecosystem
- Testing new diagram types and features
- Providing feedback on syntax and rendering

**Enterprise Users**

- Integration with internal documentation systems
- Compliance with security policies
- Custom deployment requirements

## Core Value Propositions

### 1. Instant Accessibility

- **Zero Setup:** Works immediately in any modern browser
- **No Installation:** Cloud-based with offline PWA capabilities
- **Universal Access:** Free and open source, no account required
- **Cross-Platform:** Consistent experience across devices

### 2. Real-Time Collaboration

- **Live Preview:** Instant diagram rendering as you type
- **URL Sharing:** Complete state encoded in shareable URLs
- **Version History:** Built-in diagram history and versioning
- **Export Options:** Multiple output formats (SVG, PNG, markdown)

### 3. Developer-Friendly Integration

- **Syntax Highlighting:** Monaco editor with Mermaid language support
- **Error Handling:** Real-time syntax error detection and highlighting
- **Configuration:** Full Mermaid configuration through JSON editor
- **API Integration:** External rendering services for automated workflows

### 4. Professional Quality Output

- **High-Quality Rendering:** Vector-based diagrams with crisp output
- **Theme Support:** Multiple built-in themes plus custom theming
- **Responsive Design:** Optimized for both desktop and mobile devices
- **Print-Ready:** Clean output suitable for documentation and presentations

## Feature Categories

### Core Editing Features

- **Monaco Editor Integration:** VS Code-style editing experience
- **Syntax Highlighting:** Mermaid-specific language support
- **Auto-completion:** Context-aware code suggestions
- **Error Indicators:** Real-time syntax error detection
- **Multi-tab Support:** Code and configuration editing modes

### Diagram Management

- **Live Preview:** Real-time rendering as you type
- **Pan & Zoom:** Interactive diagram navigation
- **Grid Overlay:** Optional alignment grid
- **Rough Mode:** Hand-drawn styling option
- **Theme Switching:** Light/dark mode support

### Sharing & Export

- **URL State:** Complete application state in URLs
- **History System:** Local diagram version history
- **Export Options:** SVG, PNG via external services
- **Markdown Integration:** Copy as markdown with embedded images
- **Kroki Integration:** Alternative rendering pipeline

### User Experience Features

- **Responsive Layout:** Desktop and mobile optimized interfaces
- **Keyboard Shortcuts:** Power-user keyboard navigation
- **Touch Gestures:** Mobile-friendly pan and zoom
- **Offline Support:** PWA with service worker caching
- **Accessibility:** Screen reader and keyboard navigation support

## Competitive Landscape

### Direct Competitors

- **Draw.io/Diagrams.net:** Visual diagram editor (click-and-drag)
- **PlantUML Online:** Text-based UML diagram generator
- **Lucidchart:** Professional diagramming with collaboration

### Competitive Advantages

1. **Text-Based Approach:** Version control friendly, developer-centric
2. **Mermaid Ecosystem:** Integration with documentation tools (GitLab, GitHub, etc.)
3. **Zero Friction:** No signup, immediate use, shareable URLs
4. **Open Source:** Community-driven development, extensible
5. **Modern Architecture:** Progressive web app, offline capable

### Unique Position

Mermaid Live Editor occupies a unique niche as the **official playground for text-based diagramming**, bridging the gap between developer tools and visual communication needs.
